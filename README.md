# 🍔 McDonald’s Sales Analytics Dashboard

## 📌 Overview
This project is an interactive sales analytics dashboard inspired by McDonald’s business operations, developed using Microsoft Excel, Power Query, and Data Modeling techniques. The dashboard converts raw restaurant sales data into meaningful business insights through data cleaning, transformation, KPI tracking, and interactive visualizations.

The project focuses on analyzing customer ordering behavior, identifying top-selling products, monitoring revenue trends, and evaluating category performance for data-driven decision making.

---

## 📂 Datasets Used

### 1. Menu Items Dataset
Contains:
- Item ID
- Menu Item Name
- Category
- Price

### 2. Order Details Dataset
Contains:
- Order Details ID
- Order ID
- Order Date
- Order Time
- Item ID

---

## ⚙️ Data Preparation & Modeling

The datasets were processed using Power Query and Excel Data Modeling techniques.

### Transformations Performed
- Data cleaning and formatting
- Removed null and blank records
- Merged order and menu datasets
- Revenue calculation using item prices
- Created custom time categories:
  - Morning
  - Afternoon
  - Evening
  - Night
- Weekday vs Weekend classification
- Date extraction and formatting
- Built one-to-many table relationships

---

## 📊 Dashboard Insights

### Business Performance
- **Total Orders:** 5,370
- **Total Revenue:** $61K+
- **Menu Items:** 32
- **Records Analyzed:** 12K+

### Top Revenue-Generating Products
- Meatball Marinara
- Big Mac
- Quarter Pounder with Cheese
- Angus Third Pounder
- Bulgogi Burger

### Category Analysis
- Burgers generated the highest revenue
- Chicken products showed strong customer demand
- Pasta and Sandwiches contributed consistently
- Shakes and Salads had lower sales volume

### Sales Trends
- Peak sales occurred during lunch and evening hours
- Weekend sales were higher than weekdays
- Revenue concentration was driven by a few top-performing items
